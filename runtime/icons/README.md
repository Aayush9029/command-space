# Extension icons

`catalog.json` maps Raycast API icon names and values to local SVGs. `../icon-catalog.mjs` resolves them offline; the native renderer applies colors.

Artwork includes [Phosphor Icons 2.1.1](https://github.com/phosphor-icons/core) under the [MIT license](LICENSE), plus compositions in `custom/`. Compositions using Phosphor paths retain that attribution. Raycast logo names resolve to command-key symbols.
